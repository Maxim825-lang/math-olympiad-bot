# Парсер задач

Парсер добавляет задачи в базу из публичных HTML-страниц.

## Как запустить из Telegram

Команда доступна только админу (`ADMIN_ID`):

```text
/parse https://example.com/problems
```

Можно указать несколько ссылок:

```text
/parse https://site.ru/page1 https://site.ru/page2
```

Бот ответит:

```text
✅ Парсер завершён
Найдено: 15
Добавлено: 8
Пропущено дублей: 7
Ошибок: 0
```

## Где кнопка

Открой:

```text
/admin → 🔎 Найти задачи
```

## Источники

Посмотреть, откуда задачи в базе:

```text
/sources
```

## Важно

- Парсер работает только с публичными страницами.
- Он не обходит капчи, логины, платный доступ и защиты сайтов.
- Лучше всего работают страницы, где задачи уже написаны текстом в HTML.
- Если сайт рисует задачи через JavaScript, простой парсер может их не увидеть.
- Между запросами есть задержка, чтобы не спамить сайты.
